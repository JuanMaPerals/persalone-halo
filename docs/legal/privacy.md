# PersalOne HORIZON Community — Privacy Policy

Last updated: 20 August 2026

PersalOne HORIZON Community is designed with privacy and data minimization as core principles.

## What data may be processed

The bot may process content posted in explicitly authorized Discord channels, including:

- message content
- message and thread identifiers
- channel identifiers
- timestamps
- reactions
- basic author identifiers required to maintain conversation context
- metadata associated with bug reports, feedback and agent proposals

The bot is not intended to monitor unrelated Discord channels.

## Purpose of processing

Data may be processed to:

- organize community feedback
- identify bugs and feature requests
- structure agent proposals
- summarize development discussions
- connect relevant community contributions with GitHub issues
- improve the open-source PersalOne HORIZON project

## Data minimization

Only data reasonably necessary for community and development workflows should be processed.

Secrets, credentials, sensitive personal information and unnecessary personal data should not be submitted.

## Storage and retention

Community data may be stored for as long as necessary to support project development, moderation, security and traceability.

Retention policies may be refined as the service evolves.

## Third parties

The service may interact with infrastructure and services required to operate Discord and GitHub workflows.

Community data is not sold to advertisers.

## Security

Reasonable technical and organizational measures are used to protect stored data.

No system can guarantee absolute security.

## Your requests

You may request correction or deletion of community data associated with you where reasonably identifiable and technically feasible.

## Open-source project

Some community contributions may be converted into public GitHub issues or development proposals.

Before doing so, unnecessary personal information should be removed or minimized.

## Changes

This policy may be updated as PersalOne HORIZON Community evolves.
